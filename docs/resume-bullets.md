# Resume bullets

Five bullets for a personal project, each backed by code and a measurement or test run recorded in this repository. The
numbers come from a 2-vCPU development sandbox and synthetic or hand-labeled data; keep that framing when
discussing them, and never describe the system as deployed or used in production: it was not.

**CatalogSentinel — catalog monitoring and selection-gap detection (personal project, simulated data)**
*Java 21, Spring Boot, PostgreSQL, Amazon SQS (AWS SDK v2), PySpark, React/TypeScript, Terraform*

- Built an at-least-once event ingestion pipeline with an idempotency ledger, source-version ordering, tombstones
  and a transactional outbox; benchmarked at a median of 828 events/s on 2 vCPUs (median p99 29.5 ms, nine runs)
  with zero duplicate effects across 2,000 replayed events and 80 simultaneous duplicate deliveries.
- Designed an explainable product matcher with indexed candidate retrieval (GTIN, brand and model, `pg_trgm`)
  that kept 100% of true pairs while pruning 93–98% of comparisons; error analysis lifted auto-match precision on
  unseen synthetic data from 0.920 to 0.982 at unchanged recall, with zero false auto-matches on two hand-labeled
  sets.
- Built a restartable PySpark import (manifest checksums, deterministic event ids, per-partition publish markers,
  normalization verified against a 1,000-row fixture generated by the Java code) that processed a 431,719-record
  export in 84 s on 2 cores and resumes crashed runs without losing or duplicating events.
- Profiled matching with `EXPLAIN ANALYZE` and `pg_stat_statements`, isolating trigram retrieval as 84% of
  database time (GIN index 8–12× faster than a sequential scan), and used an end-to-end A/B to reject a
  planner-tuning change that improved isolated queries 2.4× but not the workload.
- Found and fixed consistency defects in entity resolution and gap tracking test-first: wrote PostgreSQL
  integration tests that failed on the original code (5 of 6 stale-evidence scenarios, 4 of 5 reference-source
  scenarios, 4 of 4 merge scenarios), then enforced content-hash currency on every link, merge and review with
  audited supersession of human decisions, and made gap decisions follow product merges; 242 Java tests pass.

## Alternates

- Replaced in-memory reconciliation execution with a durable PostgreSQL job queue (`FOR UPDATE SKIP LOCKED` claims,
  leases fenced by owner, bounded exponential retries), with tests for API restart, process crash, executor
  saturation and two competing pollers.

- Built a React/TypeScript operations console on the real API (coverage by category, gap triage with audited,
  idempotent decisions, side-by-side match review, dead-letter replay), covered by 17 network-level tests.
- Wrote least-privilege Terraform for ECS Fargate, RDS, SQS with dead-letter queues, S3 and CloudWatch alarms, plus
  an approval-gated OIDC deploy workflow; 247 checkov checks pass with every skipped check justified (not
  deployed).
